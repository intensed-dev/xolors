# Xolors

A color-name explorer for the web.

- Search color names or HEX values
- HSV/HSB saturation-brightness picker
- Exact color conversion: HEX, RGB, HSV, HSL, HSB, CMYK and OKLCH
- Finds the closest named color using OKLab distance
- Static, GitHub Pages friendly — no build step required

## Data

Named-color data is sourced from [color-name-list](https://github.com/meodai/color-names). Check its license and attribution requirements before redistributing the dataset.

## Run

Open `index.html` or enable GitHub Pages for the repository.
